# Contributing to PokeBadges Wiki

This repository contains the public documentation website for PokeBadges.

## Contributions

- Submit documentation changes through a Pull Request.
- Keep documentation aligned with the current released PokeBadges behavior.
- Do not modify the GitHub Pages workflow unless the change is specifically required for deployment.
- Do not add third-party scripts, trackers, or remote code without maintainer approval.
- Keep the universal Our Story documentation layout and navigation style consistent.

## Review

All changes are reviewed by the repository owner before merge. The files under `.github/workflows/` and the published `site/` content are considered sensitive documentation infrastructure.
